# ProBreakthrough — Athlete Dashboard

Dashboard de performance pour les athlètes de ProBreakthrough Inc.

## Utilisation

Chaque parent reçoit un lien personnalisé :

```
https://VOTRE-USERNAME.github.io/probreakthrough-dashboard/?athlete=Prenom+Nom
```

## Première visite

1. Ouvrir le lien
2. Cliquer **Settings** (⚙️)
3. Entrer les URLs des scripts Google Apps Script
4. Cliquer **View Dashboard**

Les URLs sont sauvegardées automatiquement — pas besoin de les ré-entrer.

## Fonctionnalités

- **Match Stats** : PB Index, stats offensives/défensives, radar, historique
- **Weekly Check-In** : condition physique, mental, nutrition, heatmap
- **Benchmarks Elite** : comparaison avec les moyennes U17-U19 (MLS NEXT, PLSJQ, recherche académique)
- **Responsive** : optimisé mobile et desktop

## Déploiement

1. Créer un repo GitHub (public)
2. Pousser `index.html`
3. Settings → Pages → Source: `main` branch, `/ (root)`
4. Le site sera live en ~2 minutes
